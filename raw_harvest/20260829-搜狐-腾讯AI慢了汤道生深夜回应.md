# 腾讯AI慢了？汤道生深夜回应：马拉松才跑完第一公里

> 2026-08-25 晚，腾讯云与智慧产业事业群 CEO **汤道生**在内刊发文系统回应"腾讯做AI慢了"质疑。本文综合搜狐 2026-08-26 报道。

## 一、焦虑从何而来

- 全球大模型赛道每天刷新纪录
- 友商发布会密集：参数翻倍 / 推理提速 / 生态扩张
- 腾讯混元**曾被调侃"藏得太深"**——算力卡点 + 训练周期 + 产品节奏沉默
- **2026 混元 Hy3 架构 = 换道**：化繁为简，重质不重量，同等参数效果跃升
- 汤道生自我定位："要说一点不焦虑，那不可能"

## 二、混元 Hy3 模型核心数据

- 架构：**MoE**
- **总参数 2950 亿 / 激活参数 210 亿**
- **最长上下文 256K**
- 智能指数：Artificial Analysis 综合指数 **41**（高于同级开放权重模型 25 分的中位数，但未到最前沿）
- 价格：腾讯云公开 —— **每百万 Token 输入 1 元 / 输出 4 元**

## 三、Hy3 业务落地效果

| 产品 | 关键数据 |
|------|---------|
| **WorkBuddy** | 任务解决率 **72% → 90%** |
| **元宝** | 文档生成综合分 **+7%** |
| **ima 知识库** | 问答推理质量**净提升近 19%** |
| **OpenRouter Token 消耗** | 持续位列**全球前三** |
| **WorkBuddy 自选模型用户** | Hy3 占比 **60%** |

## 四、腾讯 AI 路径的差异化判断

### 腾讯内部观点（汤道生内刊）

> "起得早不等于赢到最后，真正拼的是**耐力、定力和场景穿透力**。"

### 外部观察（AI 资本观/界面新闻）

- 腾讯**不是最容易用一款模型制造轰动的公司**，但是**拥有真实任务最丰富的公司之一**
- 优势：数据 + 问题 + 工具 + 权限 + 结果 + 商业化机制同时存在
- Hy3 定位：**"够强、够便宜、适合进入生产的自主模型"**，而非"中国模型能力绝对顶点"
- 模型能力决定智能体能完成多复杂的任务 + 推理成本/延迟/人工兜底

## 五、与国内对手的差异化路径

| 公司 | 路径核心 |
|------|----------|
| **DeepSeek** | 模型效率 + 开放生态 + 开发者选择 |
| **阿里** | 云 + 开放模型 + 电商 + 企业服务联合 |
| **字节** | 消费产品速度 + 内容分发 + 大规模反馈 |

| **腾讯** | 多产品组成"网"，**模型从场景学习、能力迁移**（不易凭一款模型胜利） |

## 六、WorkBuddy 的故事

- **2024 年还在亏钱的 CodeBuddy**——靠 AI coding 翻身
- **2026 年初 WorkBuddy 横空出世**：界面更轻、操作更傻瓜
- 关键转折点：**腾讯文档团队回归 CSIG**——人机双写 / 资料库联动 / 非技术人员调用 AI 写方案
- 战略意义：把 AI 塞进办公桌最顺手的那个抽屉

## 七、个人 Agent vs 服务 Agent

- **孪生兄弟**而非替代
- 个人 Agent：订咖啡 / 写周报 / 管日程
- 服务 Agent：嵌入 ERP / 连通 CRM / 调度供应链
- **真正分水岭**：模型与产品深度咬合，而非模型做好再塞给产品
- 共创机制：**混元团队 × 元宝团队 × WorkBuddy 团队——Co-Design**

## 八、新 AI 节奏（2026 转向）

- **不抢首发，但求扎实**
- **不炒概念，但重交付**
- **不堆参数，但精场景**

> "**真正的 AI 护城河，不在服务器集群里，而在每一次用户点击、输入、等待和满意的 0.3 秒之间。**"

## 九、对工程人的启示

- **Co-Design 是 AI 时代产品工程的底层逻辑**：模型团队 × 产品团队 × 业务团队共创，而非流水线交付
- **"够强、够便宜、适合进入生产"是 2026 评价模型的新三件套**：参数不是唯一指标
- **企业 Agent 的机会窗口已开**：服务 Agent（ERP/CRM/供应链调度）比个人 Agent 商业化路径更清晰
- **AI 不会百米冲刺，但一定是马拉松**：耐力 + 定力 + 场景穿透力是腾讯押注的"慢变量"
