# KB 2.0：Karpathy知识库多Agent改造

## Karpathy原版问题
- 没有质量控制（垃圾进垃圾出）
- 知识是孤岛（文档间无关联）
- 没有健康检查
- 多Agent无法协作

## 五大改造
1. **自动入库流水线**：抓取→结构化→质量打分→路由（≥18 keep, 12-17 queue, <12 discard）
2. **交叉链接**：入库后自动搜索已有笔记互链
3. **三层索引**：index.md（目录）+ recent.md（最近10条）+ active.md（当前研究）
4. **Lint健康检查**（每周自动）：矛盾/孤立/缺失/过时/反写/规则6项
5. **多Agent协作规范**：读/Ingest/Crosslink/Lint可自主，删/归档/Writeback须问用户
