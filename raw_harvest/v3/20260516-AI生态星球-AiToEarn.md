# AiToEarn：内容中台+AI Agent

## 五大功能模块
1. **超级Agent**：自动生成/发布/运营内容
2. **13平台分发**：抖音/小红书/B站/YouTube/TikTok/视频号/LinkedIn等
3. **热点雷达+爆款库**：实时热点+10w+点赞案例库
4. **评论挖掘**：自动识别"求链接"高转化评论
5. **数据看板**：跨平台流量对比

## Docker一键部署
```bash
git clone https://github.com/yikart/AiToEarn.git
cp env.example .env  # 配置密码和密钥
docker compose up -d
```

## 访问地址
Web前端：http://localhost:3000
后端API：http://localhost:3002
