# Claude Code里敲一行命令，52个文件变知识图谱

## graphify
Claude Code的Skill插件，`/graphify`命令将任意文件夹转为可查询知识图谱。

## 五阶段流水线
1. **检测**：按扩展名分为代码/文档/PDF/图片
2. **提取**：代码用tree-sitter AST解析，文档用Claude提取概念，PDF提取引用网络，图片用Claude Vision
3. **建图+聚类**：NetworkX构建图+Leiden算法社区发现
4. **分析+报告**：核心节点、意外关联、推荐问题
5. **导出**：交互式HTML、Obsidian笔记库、JSON持久化

## 关键数据
- 52文件测试：Token从428K降至6K（降低71.5倍）
- 81%关系为EXTRACTED（明确存在），19%为INFERRED（推理得到）
- 可信度标签：EXTRACTED / INFERRED / AMBIGUOUS

## 安装
```bash
pip install graphifyy && graphify install
```
