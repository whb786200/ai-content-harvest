# PromptHub：Prompt和Skill管理器

## 痛点
多工具（Claude Code/Cursor/Codex/Windsurf/Gemini CLI）同时使用时，Prompt/Skill分散难管理。

## 四层核心能力
1. **Prompt管理**：分类存储、变量模板、版本回溯对比
2. **Skill管理**：扫描本地Skill、预览结构、版本差异对比
3. **多平台分发**：一键安装到Claude Code/Cursor/Codex/Windsurf/Gemini CLI
4. **资产安全**：本地优先+WebDAV多设备同步

## 关键认知
Skill是独立于Prompt的资产类型 — 封装了指令、执行边界、配套资源的可复用能力包。
