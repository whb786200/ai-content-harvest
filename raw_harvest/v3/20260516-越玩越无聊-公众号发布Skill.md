# AI直接发公众号的Skill

## MCP方案的致命问题
1. MCP进程经常崩溃（tool not found）
2. 多账号需开多个进程存密钥

## Skill方案优势
微信公众号API只有5个端点，全是无状态REST调用。Token两小时过期，每次现取。Skill+curl更可靠。

## 微信公众号HTML踩坑
| 坑 | 说明 |
|----|------|
| `<strong>`不能加style | 微信渲染成块级元素 |
| 列表标签间不能有空白 | 否则出现额外空白项 |
| 外部图片全被屏蔽 | 必须上传到微信CDN |
| class/id全被剥离 | 所有样式必须inline |
| 表格深色背景 | 白色文字可能变透明 |
