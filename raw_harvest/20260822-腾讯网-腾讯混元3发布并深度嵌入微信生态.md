# 混元动态：腾讯混元3发布并深度嵌入微信生态

> 收割自腾讯网"混元动态"栏目（2026-08-20），涵盖混元3发布、算力倾斜、人事重组、Agent论文、全球开放与财报写入六大要点。

## 1. 腾讯混元3发布并深度嵌入微信生态
8月20日，腾讯混元3正式发布，未单独作为 API 推给开发者，而是直接打通微信搜索、公众号创作辅助与小程序智能交互，依托微信日活形成结构性分发优势。[来源:小余观行业]

## 2. 腾讯算力优先倾斜混元与 WorkBuddy
8月20日，腾讯 Q2 资本开支达 528 亿元，明确算力优先用于混元大模型训练与 WorkBuddy 推理，标志其"大模型+应用"双线并进、All in AI 主攻办公的战略定调。[来源:小冉学习笔记]

## 3. 混元人事重组：蔺旭东加盟、姚顺雨掌舵基础模型部
8月19日消息，原 xAI 多模态理解负责人蔺旭东已入职腾讯混元任多模态内容生成算法负责人；腾讯将大语言模型部与多模态模型部合并为"基础模型部"，由姚顺雨全面接管，技术路线聚焦上下文与推理能力。[来源:在无锡双休的小柠檬]

## 4. 混元发布两篇 Agent 技术论文
8月19日，腾讯混元团队接连放出 Harness Handbook 与 RST 两篇工作，分别解决 Agent 执行框架（harness）自动维护与长程终端任务递归合成训练数据问题，验证可迁移提升模型终端能力。[来源:PaperAgent]

## 5. Hy3 通过 WorkBuddy、腾讯云 TokenHub 向全球开放
8月，Hy3 经 WorkBuddy、腾讯设计妙境（Miora）与腾讯云 TokenHub 向全球用户、企业和开发者开放；海外采用"腾讯 Hy"品牌，中国市场仍沿用"混元"名称，限免活动延至 8月31日。[来源:AI小小狐]

## 6. 腾讯 Q2 财报将 WorkBuddy 写入，成最受欢迎效率智能体
WorkBuddy 被写入腾讯 2026 年一季度财报，按日活跃账户计为中国最受欢迎的效率 AI 智能体服务；7月30日联合腾讯文档上线"人机双写"，定位"AI 时代的 Office"入口。[来源:恒动力MAX]
