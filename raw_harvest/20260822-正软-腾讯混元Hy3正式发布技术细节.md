# 半年重建，一次交卷：5分钟生成3D跑酷小游戏，腾讯混元 Hy3 正式发布

> 收割自正软商城（2026-08-18）。混元今年1月底启动底层基础设施重建，不到半年跑通"底层重构→产品反哺"完整研发链路。

## 架构与参数
- **MoE 架构取舍**：总参数 295B、激活参数仅 21B。总参足够大以保证知识容量与复杂任务承载力；激活参数压到 21B，每次推理只调动一小部分权重，服务成本和时延随之降下来。
- **快慢思考融合**：相比 4 月 preview 版本，在后训练算力、数据质量与多样性上全面加码，以较小尺寸首次接近国内外大尺寸旗舰模型效果。
- **上下文**：支持 256K 上下文长度。

## 盲测与质量
- 内部 270 位专家基于真实工作的盲测：Hy3 均分 **2.67 / 4**，优于 GLM 5.1 的 2.51 / 4，尤其在前端、数据与存储、CI/CD 等工程类别优势显著。
- 办公场景内部测评：任务成功率从 72% 升至 90%，平均耗时缩短 34%。
- 幻觉率从 12.5% 降到 5.4%，常识错误率从 25.4% 降到 12.7%。
- 多轮问题率从 17.4% 降到 7.9%，长对话基准 MRCR 从 42.9% 跳到 75.1%。
- 工具调用跨脚手架泛化：Codebuddy、Cline、KiloCode 在 SWE Bench Verified 上分数标准差压在 4 个百分点以内。

## 成本与开放
- 与 GLM-5.2 比，高频办公任务 token 消耗更低：文档处理省 47.4%、PPT 制作省 49.0%。
- 定价：输入 1 元/百万 tokens、输出 4 元/百万 tokens，命中缓存仅 0.25 元。
- 开源：Apache 2.0 协议，全球开发者可免费商用，"day 0"接入 Hugging Face 与 ModelScope，后续覆盖 OpenRouter、Hermes、Kilo、Cline 等海外平台。

## 产品协同（Co-Design）
- 元宝借 Hy3 的 Agent 能力上线文件交付，常识错误率与幻觉率均下降超一半。
- ima 的 Agent 系统稳定性达 95.1%，知识库问答推理质量净提升近 19%。
- Marvis 核心场景任务完成率 93.7%，6 个 Agent 协作派发正确率 92%。
- 公众号 AI 分身意图识别准确率 98.94%；WeGame AI 助手多轮推理成功率 92%、幻觉率从 4.5% 降至 2.8%。

## 5分钟3D跑酷小游戏
用 Hy3 在 WorkBuddy 里从一句话需求到上线可玩 3D 跑酷小游戏（单文件 HTML，Three.js 本地引用保证离线运行），全程无人工参与，用时约 5 分钟。已部署为公开试玩网页。
