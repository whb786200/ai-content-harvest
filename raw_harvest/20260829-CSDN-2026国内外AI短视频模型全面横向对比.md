## 二、分维度深度评测

### 2.1 画质/物理仿真/人物写实
- **可灵 Kling 3.0**：写实第一梯队，人体骨骼/皮肤光影/动作物理强；短板：电影镜头语言理解弱于 Seedance，高并发排队长，续写人物漂移
- **Seedance 2.5**：镜头叙事突出，自动识别远/特/推拉摇移；中文极强；原生音画对口型；短板：高速打斗物理弱，跨镜头切换容易五官/服装漂移（**做短剧必须配参考图锁角色**）
- **Vidu Q3**：亮点是**多主体同时角色锁定**；缺点：大动态易崩坏，无原生音频
- **Wan 3.0**：闭源 API + **开源权重**；可本地私有化部署；缺点：写实易失真，无原生音频
- **海外**：Veo 3.1 盲测顶尖但权限难拿；Sora 2 即将下线

### 2.2 短剧核心痛点：角色一致性 / 跨镜头漂移
> **没有任何模型彻底解决跨镜头人物漂移**，只能靠工程手段：角色参考图、IP-Adapter、锚帧续写、人工筛选重生成。

| 模型 | 多角色支持 | 漂移概率 |
|------|-----------|---------|
| Vidu Q3 | ✅ 最强（多主体锁定） | 相对最低 |
| 可灵 3.0 | 中（多角色互相干扰） | 单人物优秀 |
| Seedance 2.5 | 中（跨镜头变脸，必须参考图） | 单镜头优秀 |
| Wan 3.0 | 弱（需外部图像模型） | 完全依赖外部 |

### 2.3 音频 / 口型同步
- **原生音画同步**（可灵、Seedance、Sora 2、Veo 3.1）：自带音频大幅减少后期；**Seedance 中文口型匹配最强**
- 其余模型：需外部 TTS + 音视频对齐，短剧需写口型对齐逻辑

### 2.4 价格对比（2026-08 参考）

| 模型 | 网页会员 | API 按量折算 1080P | 免费额度 | 适合 |
|------|---------|------------------|---------|------|
| 可灵 3.0 | 58–66 元/月 | 0.6–1.0 元/秒 | 每日 66 免费积分 | 精品短剧，少量高质量镜头 |
| Seedance 2.5 | 会员积分制 | 0.6–1.3 元/秒 | 少量免费 | 创意短视频、广告片头、测试原型 |
| Vidu Q3 | 会员订阅 | 0.4–0.5 元/秒 | 错峰免费 | 大批量短剧镜头，控制成本 |
| Wan 3.0 | 千问 APP 灰度 | 0.3–1.2 元/秒 | 开源本地运行零调用费 | 私有化、学生项目、技术原型 |
| Runway Gen-4.5 | $12/月起 | $1.2–1.8/秒 | 少量初始积分 | 海外创意后期（国内不适合量产） |

> 成本算账：1 分钟 AI 短剧，全 AI 画面成本 25–60 元/分钟；开源 Wan 本地仅显卡算力。

### 2.5 API / 工程友好度 / 私有化
- **可灵 / Seedance / Vidu**：完整 REST API + 异步回调，全部**仅云端**，**不提供权重**
- **Wan 3.0**：云端 API + **开源权重**，可本地 GPU 部署（毕业设计、简历、内部原型）
- **海外**：网络/版权/合规多重问题，国内业务不建议

## 三、选型决策矩阵

| 业务场景 | 优先选择 | 备选 | 说明 |
|---------|---------|------|------|
| 写实精品竖屏短剧（少量高质量） | **可灵 3.0** | Seedance 2.5 | 人物动作写实，预算充足 |
| 批量量产 AI 短剧/漫剧 | **Vidu Q3** | Wan 3.0 | 多角色频繁切换，追求性价比 |
| 创意短视频/广告片头 | **Seedance 2.5** | 可灵 3.0 | 镜头语言 + 中文提示词友好 |
| 毕业设计/简历/本地私有化 | **Wan 3.0** | Vidu API | 开源权重本地跑完整流水线 |
| 二次元/风格化艺术短片 | PixVerse V6 | Pika | 不适合真人写实 |
| 海外业务 | Runway Gen-4.5 | PixVerse | 不适合国内中文短剧 |

## 四、AI 短剧 7 个硬坑（面试高频）

1. **不存在一键生成完整短剧**：必须分段生成 + 后期缝合
2. **角色一致性是工程问题**：必须引入角色参考图、锚帧、IP-Adapter
3. **画面内文字几乎全乱码**：字幕必须后期叠加
4. **成本/质量不可三角**：高清=贵+慢，批量=画质降
5. **版权商用坑**：免费仅限非商用；商用必须企业授权；不要传真人明星肖像
6. **国内风控审核**：通过率 60–80%，需设计失败重试/任务降级
7. **原生音频不是万能**：长多镜头拼接仍会错位，最终项目仍需音频校准

## 五、对工程人的启示

- **AI 视频已过 "Demo 好看、生产不可用" 阶段**：2026 进入流水线量产时代
- **完整项目 ≠ 调 API**：完整短剧链路 = 剧本 → 分镜 → 角色资产 → 分段生成 → TTS → 音画对齐 → 批量调度
- **选型要写清取舍**：选 Vidu 要写物理动作弱的补偿；选 Wan 要写画质短板如何提升一致性
- **Sora 2 2026-09-24 退场**：所有基于 Sora 的业务系统半年内必须迁出
