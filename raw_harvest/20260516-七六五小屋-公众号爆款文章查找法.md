# 做公众号，90%人不知道10万+爆款文章在哪里找？

## 五种找爆款方法

### 1. 微信搜一搜
- 路径：PC/手机→搜一搜
- 方法："领域 关键词"搜索，按最热排序
- 标准：优先半年内10万+爆文

### 2. 订阅号看一看
- 路径：手机端→公众号→看一看
- 注意：用小号刷，避免信息茧房

### 3. 爆款文评论区
- 用户讨论=真实需求=新选题

### 4. 新榜低粉爆文榜
- 路径：新榜官网→低粉爆文榜
- 价值：低粉也能出爆款，复制其逻辑

### 5. 微信指数
- 路径：发现→搜一搜→微信指数
- 用法：验证关键词热度

## 选题质量判断
- 10万+ → 直接对标
- 1万-10万 → 参考
- <1千 → 放弃
