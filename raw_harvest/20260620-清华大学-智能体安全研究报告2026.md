# 清华大学：智能体安全研究报告2026

**来源：** 搜狐/清华大学清新研究团队 | **日期：** 2026-06-09 | **URL：** https://www.sohu.com/a/1034036233_468661

## 核心结论
智能体安全已从模型层转向**运行时系统安全**。Agent = 带权限的运行时系统，安全边界 >> 普通对话模型。企业核心竞争力在于**安全控制平面**，而非单个大模型。

## Agent Safety 公式
`Agent Safety = 身份 + 策略 + 工具 + 日志`

## 七大核心内容

### 1. 三大核心判断
- Agent非聊天机器人，是**带权限的运行时系统**
- 仅依靠提示词无法保障工具调用安全
- 企业核心竞争力 = 安全控制平面（非单个模型）

### 2. 十大高频风险
| 风险类型 | 代表风险 |
|---------|---------|
| 高频 | 目标劫持、提示词注入、工具滥用、身份/权限滥用 |
| 持续性 | 记忆污染、上下文投毒（跨任务延续） |
| 扩散类 | 沙箱逃逸、供应链污染、多Agent级联失败 |
| 衍生 | 数据泄露、意外代码执行、审计缺失 |

### 3. 七层安全控制框架
1. **身份层**：独立身份链路，禁止长期持有人类凭证
2. **权限层**：最小权限+短期可撤销，高风险动作强制审批
3. **工具层**：风险标签+调用规则，调用前后策略校验
4. **上下文层**：隔离不可信数据，防范上下文投毒
5. **记忆层**：读写管控，版本回溯+删除回滚
6. **沙箱层**：代码/文件/命令强制隔离，限制网络与资源
7. **审计&人工层**：全量操作日志(Action Ledger)，高风险人工审批门

### 4. 安全控制平面架构
- Agent/工具注册中心：全量登记，风险等级标注
- 策略引擎：每次工具调用前校验身份/权限/数据
- 基础安全：上下文防火墙、数据脱敏+DLP、沙箱隔离
- 审计应急：全链路日志、熔断机制、故障回滚

### 5. 落地路线图
- **0-30天**：资产盘点，梳理所有Agent与高权限工具
- **30-60天**：搭建权限/日志/审批基线，统一安全策略
- **60-90天**：低风险场景试点，红队渗透测试
- **90-180天**：平台化，注册中心+策略引擎+沙箱
- **一年目标**：统一安全控制平面，核心Agent全面接入

### 6. 成熟度五级
- L1 只读 → L2 受限工具 → L3 半自动 → L4 闭环自治 → L5 高保证自治
- 建议企业优先落地 **L2-L3**

### 7. MCP协议风险
- MCP简化工具接入，但同步扩大攻击面
- 风险：权限滥用、隐私泄露、代码执行
- 需将MCP工具纳入安全控制平面管理

## 对工程管理的启示
1. **代建项目AI应用**：Agent用于安全巡检、合规审查，必须配置安全控制平面
2. **多Agent协作**：级联失败风险需提前评估，参考七层框架设计
3. **落地优先级**：先资产清单→权限管控→全量日志，再放开工具能力
