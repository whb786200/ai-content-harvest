# Agent 记忆架构 2026：从认知科学到生产级实现的技术全景

> 收割自 x7peeps（2026）。系统梳理 Agent 记忆的三层认知模型、混合存储、框架对比、过时检测、安全隐私与 2026 趋势。

## 1. 三层认知模型
| 记忆类型 | 定义 | Agent 映射 | 核心特征 |
|---------|------|-----------|---------|
| 情景记忆 | 特定事件（何时何地） | 对话日志/工具轨迹 | 时序锚定 |
| 语义记忆 | 声明性事实/关系 | 用户画像/实体关系图 | 无时间性 |
| 程序记忆 | "如何做"的技能流程 | 工作流/工具使用习惯 | 行为指导 |

- 程序记忆工具化程度最低；Letta 的 sleeptime agent（对话间隙后台重写整合记忆块）最接近实用化。

## 2. 混合向量-图谱存储=2026事实标准
- 纯向量局限：关系盲区（答不了"Alice与Bob关系"）、时序失忆、冲突无感。
- 混合架构：向量库(语义相似/BM25/模糊) + 知识图谱(实体关系/时序标注/冲突检测) → 多信号检索融合。
- Mem0 v3 三通道并行（Vector+BM25+Entity Matching），LoCoMo 时间推理 +29.6、多跳 +23.1。
- Zep/Graphiti：Neo4j 底层、双时序标注（事件时间+摄入时间）、不调 LLM 低延迟；LongMemEval 63.8% vs Mem0 49.0%。
- Mem0 v3 移除外部图存储改内置实体链接。

## 3. 框架对比
| 框架 | Stars | 范式 | 领先维度 |
|------|-------|------|---------|
| Mem0 | ~48K | 向量+实体链接 | 规模/易用性，LoCoMo 92.5 |
| Zep/Graphiti | ~24K | 时序知识图谱 | 时序推理领先15分 |
| Letta | ~21K | OS风格运行时 | 长时间运行Agent |
| Cognee | ~12K | ECL管道+类型化图谱 | 知识密集型 |

- Mem0 四层作用域：User(跨会话永久)/Agent/Session/Organization，检索排名 用户>会话>原始历史。
- Letta 分级存储：Core(RAM永驻)/Archival(向量)/Recall(SQL日志)/Filesystem；LoCoMo 文件系统模式 74.0%。

## 4. 记忆过时检测
时间衰减 / 显式过期 / 主动验证(LLM定期一致性检查) / 用户反馈驱动更新。

## 5. 开放问题
跨会话身份一致性、大规模时序抽象（百万级记忆）、记忆过时自动检测、程序记忆管理、评测覆盖不足（LoCoMo/LongMemEval 不覆盖程序记忆与抗投毒）。

## 6. 安全与隐私
- 记忆投毒：构造交互让 Agent 记恶意信息；防御=输入验证/来源分级/记忆审计/沙箱隔离。
- GDPR 被遗忘权：需从向量、图谱、缓存、备份彻底清除，图记忆与缓存层实现成本高。

## 7. 2026 关键趋势
混合存储默认化 / 评测标准化(LoCoMo·LongMemEval·BEAM) / 记忆即上下文工程(Anthropic) / 声明式与自动提取融合(CLAUDE.md+管道) / 隐私优先(OpenMemory MCP 本地优先)。
未来18个月最值得关注：**程序记忆工具化**（学"怎么做"）+ **跨Agent记忆共享**。

## 评测基准
- LoCoMo：1540问题/4类，多会话黄金标准。
- LongMemEval：500问题/6类，时序推理终极压力测试。
- BEAM：1M/10M token，10类，生产规模相关性最高。
- 最佳成绩：Mem0 v3 LoCoMo 92.5 / LongMemEval 94.4 / ~6900 token每查询。
