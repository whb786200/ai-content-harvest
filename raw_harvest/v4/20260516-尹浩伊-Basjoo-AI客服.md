# Basjoo AI客服系统

## 项目信息
- **GitHub**: github.com/haoyiyin/basjoo
- **技术栈**: FastAPI + Next.js + Qdrant + Docker Compose

## 核心功能
1. 24小时自动接待，部署在自有服务器
2. 多语言自动识别与回复（西班牙语/法语/阿拉伯语等）
3. 引导客户留联系方式
4. 对话记录管理与线索跟进

## 后台功能
| 功能 | 说明 |
|------|------|
| Agent配置 | 选模型、调参数、设人设，Playground测试 |
| 知识库 | 导入官网链接自动爬取、上传PDF/FAQ |
| Q&A管理 | 手动/批量创建问答对，优先级最高 |
| 会话监控 | 实时查看、一键接管回复 |
| Widget外观 | 颜色/位置/语言/自动弹出自定义 |

## 部署
```bash
curl -fsSL https://raw.githubusercontent.com/haoyiyin/basjoo/main/install-deploy.sh | sudo sh
```

## 适用场景
外贸独立站、跨境电商、需要多语言客服的中小企业
