# Jellyfish（水母）— 一站式AI短剧生产

## 项目信息
- **GitHub**: github.com/Forget-C/Jellyfish（3.3K+★）
- **许可证**: Apache-2.0（可商用）
- **技术栈**: React 18 + TypeScript + FastAPI + MySQL + RustFS

## 一致性三重保障
1. **全局种子防漂移**：整个项目统一随机种子
2. **风格强制继承**：所有生成内容自动继承全局风格
3. **资产复用体系**：角色/场景/道具/服装全生命周期管理（项目级+全局级双层库）

## 六步工业化流水线
1. 剧本输入
2. 智能分镜（景别/角度/运镜/情绪/时长/氛围）
3. 角色/场景/道具管理（首尾/关键帧独立提示词）
4. AI视频生成
5. 后期剪辑（多版本管理对比）
6. 一键导出成片

## 可视化导演体验
- 全方位调节：景别/角度/运镜/情绪/时长/氛围
- 多版本管理对比
- 实时预览

## 部署
Docker一键部署，推荐NVIDIA RTX 30系列以上，显存12GB+
