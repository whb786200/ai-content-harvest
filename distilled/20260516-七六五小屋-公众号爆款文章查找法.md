# 做公众号，90%人不知道10万+爆款文章在哪里找？

## 核心主题
公众号爆款选题的5种系统化工具体：从微信自有功能（搜一搜/看一看/微信指数）到第三方平台（新榜），建立可持续的爆款选题来源体系。

## 方法论/认知框架

**爆款选题五源框架**（从本文蒸馏，可复用）
1. **搜索引擎法**（微信搜一搜）：关键词="领域+核心词"，按最热排序，优先半年内10万+
2. **信息茧房突破法**（订阅号看一看）：用小号刷，避免大号算法茧房
3. **需求反向推导法**（爆款文评论区）：用户讨论=真实需求=新选题金矿
4. **低粉爆文对标法**（新榜低粉爆文榜）：低粉也能爆→逻辑可复制，适合新手对标
5. **热度验证法**（微信指数）：选题前先验证关键词热度，避免自嗨

**选题质量三级判断标准**
| 阅读量 | 行动建议 |
|--------|----------|
| 10万+ | 直接对标，全文拆解 |
| 1万-10万 | 参考框架，差异化改写 |
| <1千 | 放弃，无爆款潜力 |

## 操作流
### 第一步：建立选题监控清单
每周用「微信搜一搜」搜索本领域3个核心关键词，按最热排序，记录Top5文章标题+阅读量

### 第二步：突破信息茧房
用备用微信号（小号）刷「看一看」，记录跨领域爆款标题模式

### 第三步：评论区挖需求
找到本领域爆款10万+文章，精读评论区，提取用户痛点关键词→形成新选题

### 第四步：新榜验证可复制性
查新榜低粉爆文榜，找粉丝数<1万但出爆文的账号，分析其标题/封面/结构

### 第五步：微信指数确认热度
输入选题关键词→确认趋势上升→开始写作

## 金句
> "爆款不是碰出来的，是找出来的。90%的人不知道去哪里找，所以10万+永远属于那10%。"

## 适用场景
- 公众号新手：0粉丝起步，需要可复制的爆款逻辑
- 内容运营：选题枯竭，需要系统化选题来源
- 不适用：已经有稳定爆款能力的头部账号（需要差异化而非对标）
