## 方法论/认知框架

**短剧推广三步法**（从本文蒸馏）
```
Step1: 注册右豹APP → 绑定红果短剧 → 获取推广链接
Step2: 选剧策略 → 避"总裁/神医/赘婿" → 选"重生复仇/逆袭打脸" → 评分5分 → 单集10-15元
Step3: 发视频 → 抖音（高光片段+左下角链接）/ 快手（冲突对话+小程序）/ 视频号（催泪片段+下方链接）
```

## 操作流

### 第一步：注册
1. 应用商店搜"右豹"
2. 微信登录，绑定红果短剧
3. 获取推广链接

### 第二步：选剧
1. 避开"总裁/神医/赘婿"（同质化严重）
2. 优先"重生复仇/逆袭打脸"（节奏快）
3. 评分 5 分以上
4. 单集 10-15 元

### 第三步：发视频
- **抖音**：剪高光片段（打脸/反转），"点击左下角看全集"
- **快手**：剪冲突对话，"点击小程序观看"
- **视频号**：剪催泪片段，"点击下方链接"

### 第四步（进阶）：每日运营
- 每天 3 条不同视频（避开限流）
- 晚 8-10 点发布（转化率比白天高 3 倍）
- 不提"赚钱""佣金"（触发限流）
- 用"一键剪辑"防搬运

## 实操数据
- 爆款 12 万播放 → 38 单 → 570 元
- 佣金比例：30%-50%

## 金句
> "选剧比推广更重要——重生复仇永远比总裁神医好卖。"

## 适用场景
- 短视频副业：0成本投入，时间投入低
- 宝妈/学生副业：15分钟/天，月入3000+可行
- 不适用：已有稳定收入者（收益天花板低）
