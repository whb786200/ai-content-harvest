# Seedance2.0生成古诗词视频五步法

## 核心主题
Seedance2.0 古诗词视频五步法：分镜提示词→分镜图片→朗读音频→分镜视频（首尾帧模式）→剪映剪辑，以冯延巳《醉花间》为示例。

## 方法论/认知框架

**Seedance2.0 古诗词视频五步法**（从本文蒸馏）
```
Step1: 豆包拆诗词意境 → 8-10个分镜提示词
Step2: 豆包图片生成 → 分镜图（统一风格+固定人物）
Step3: tts工具 → 朗读音频（选语音/风格/语速）
Step4: 即梦首尾帧模式 → 分镜视频（5秒/段）
Step5: 剪映 → 串联+配音+BGM+去水印
```

**Seedance2.0 首尾帧模式最佳实践**
- 相邻分镜图设为"首帧"和"尾帧"→ AI 自动插帧生成中间过渡
- 时长：5秒/段，积分消耗：25积分/段
- 效果：比单图转视频更流畅，画面连贯性好

**古诗词 AI 视频画面统一原则**
- 固定风格（三选一）：清新漫画/新中式古风/淡雅水墨
- 固定人物：白衣古装少年（贯穿全文）
- 点击"变清晰"后下载（确保画质）

## 操作流

### 第一步：生成分镜提示词（豆包）
将诗词按意境拆分为8-10个镜头，每个镜头包含画面描述（场景/人物/动作/色调）

### 第二步：生成分镜图片（豆包）
1. 统一风格（清新漫画/新中式古风/淡雅水墨）
2. 固定人物（白衣古装少年）
3. 点击"变清晰"后下载高清图

### 第三步：生成朗读音频（tts.wangwangit.com）
1. 输入诗词全文
2. 选择语音+朗诵风格+语速
3. 下载音频文件

### 第四步：生成分镜视频（即梦首尾帧模式）
1. 选择"首尾帧"模式
2. 将相邻分镜图设为首帧和尾帧
3. AI 自动插帧生成平滑过渡视频（5秒/段）
4. 积分消耗：25积分/段

### 第五步：剪映剪辑
1. 串联所有5秒分镜视频
2. 添加朗读音频配音
3. 添加古风 BGM
4. 扩大画幅去水印
5. 导出

## 金句
> "首尾帧模式是把两张画变成一段电影的魔法——相邻分镜图的过渡越自然，成品越像电影。"

## 适用场景
- 诗词教学：古诗词可视化
- 文创 IP：古风内容 AI 化
- 不适用：需要多角色复杂动作的诗词（首尾帧模式适合静态→动态过渡）
