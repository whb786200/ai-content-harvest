# Karpathy知识管理全解蒸馏

## 核心主题
对比三位代表人物的知识管理方法：Karpathy（LLM驱动知识库）、Lex Fridman（Obsidian+终端交互）、kepano（Obsidian创始人，防AI污染），提炼适合工程从业者的知识管理架构。

## 方法论/认知框架

**三位代表人物对比**
| 人物 | 身份 | 方法论 | 核心工具 |
|------|------|--------|----------|
| **Karpathy** | AI研究者 | LLM驱动个人知识库5模块 | LLM-Wiki |
| **Lex Fridman** | 播客主持人 | Obsidian+Cursor+自研终端前端 | Obsidian CLI |
| **kepano** | Obsidian创始人 | 防AI内容污染，双仓库物理隔离 | Obsidian原生 |

**Karpathy 5模块框架**
```
1. 原始资料收集（RAW）
2. LLM提取结构化知识
3. 知识库组织与链接
4. 自然语言查询
5. 定期维护与健康检查
```

**kepano核心原则**
> "不要外包理解力" — AI生成内容必须标注来源，双仓库物理隔离（人工仓库 vs AI仓库）
