# WeWrite — 公众号AI助手蒸馏

## 核心主题
WeWrite：公众号全流程AI助手，触发"写一篇公众号文章"即可自动完成热点抓取→选题评分→框架选择→素材采集→内容增强→写作→SEO优化→AI配图→排版→草稿箱推送的完整闭环。

## 6大高频功能

| 功能 | 说明 |
|------|------|
| 小绿书图片帖 | 上传图片→3分钟生成横滑轮播→草稿箱 |
| AI配图 | 通义千问(默认)+Baoyu Gemini(自定义) |
| ljg-card铸图 | prompt→精美卡片PNG |
| 热点抓取+选题 | 微博/头条/百度热搜→10个选题+评分 |
| 风格学习 | 编辑锚点→"学习我的修改"→下次贴合风格 |
| 16套排版主题 | 科技感/商务风/文艺风/少数派风格 |

## 全流程链路
```
热点抓取 → 选题评分 → 框架选择 → 素材采集 → 内容增强
  → 写作 → SEO优化 → AI配图 → 排版 → 草稿箱推送
```
