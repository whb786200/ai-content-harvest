# Obsidian + AI 第二大脑实战 — 蒸馏

## 核心主题
Obsidian+AI打造第二大脑的完整实战路径：7000+社区插件+4种AI方案（BMO Chatbot/Local REST API/MCP+Claude Code/Ollama）+3种工作流（研究/写作/学新领域）+4周启动计划，核心数据：知识检索从3-5分钟→30秒、文章初稿从2-3小时→30分钟。

## 方法论/认知框架

**AI时代知识管理范式转移**
```
传统PKM → AI时代PKM
存储：文件夹层级 → 图谱+向量
检索：关键词搜索 → 语义理解+推理
组织：人工分类 → AI自动聚类关联
复用：主动提取 → AI主动推送
创作：仅提供素材 → AI直接参与创作
```

**Obsidian核心三件套**
```
1. 双向链接：[[笔记标题]] / [[标题|显示]] / ![[标题]]嵌入
2. 图谱视图：全局/局部/星形三级关联
3. 块引用：![[笔记#^块ID]] 精准复用段落
```

**三种实战工作流**
```
研究：项目总览笔记(Templater) → 论文笔记(YAML) → AI分析(分歧+共识) → 图谱验证(孤岛=空白)
写作：收集素材 → 整理关联 → AI提炼框架 → 草稿生成 → 人工润色
学习：泛读 → 建立链接 → AI辅助深化 → 间隔重复复习
```

## 工具链

### 四种AI方案对比
| 方案 | 配置难度 | 模型能力 | 隐私 | 离线 | 适合人群 |
|------|:---:|:---:|:---:|:---:|------|

| **Local REST API** | ⭐⭐ | 取决于外部 | 数据经云端 | ❌ | 开发者 |
| **MCP+Claude Code** | ⭐⭐⭐ | 云端最强 | 数据经云端 | ❌ | 高级用户 |
| **Ollama** | ⭐⭐ | 本地较弱 | 完全本地 | ✅ | 隐私敏感用户 |

### 推荐路径
```
初次接触 → BMO Chatbot
有技术背景 → MCP+Claude Code
有隐私需求 → Ollama
```

## 关键洞察

1. **核心功能完全免费**：Obsidian免费+本地存储+7000+插件，AI方案可选付费
2. **图谱是发现知识空白的利器**：孤岛笔记=研究空白，图谱审计比手动检查高效10倍
3. **五大常见陷阱**：插件依赖（兼容崩溃）、图谱迷失（500+笔记成乱麻）、AI过度依赖（变拐杖）、数据备份（必须Git+云盘）、配置过度（最小可行起步）
4. **4周启动足够**：W1基础→W2接AI→W3走工作流→W4+迭代优化
5. **"最小可行系统"起步**：不需要一步到位，先跑通再优化
