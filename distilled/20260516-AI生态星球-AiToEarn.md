# AiToEarn — 全栈Agent蒸馏

## 核心主题
AiToEarn：开源内容中台+AI Agent，覆盖内容生成/13平台分发/热点雷达/评论挖掘/数据看板五大模块，Docker一键部署，MIT协议。

## 五大功能模块
| 模块 | 能力 |
|------|------|
| **超级Agent** | 自动生成/发布/运营内容 |
| **13平台分发** | 抖音/小红书/B站/YouTube/TikTok/视频号/LinkedIn等 |
| **热点雷达+爆款库** | 实时热点 + 10w+点赞案例库 |
| **评论挖掘** | 自动识别"求链接"等高转化评论 |
| **数据看板** | 跨平台流量对比 |

## 操作流

**Docker一键部署**
```bash
git clone https://github.com/yikart/AiToEarn.git
cp env.example .env
docker compose up -d
# Web前端：http://localhost:3000
# 后端API：http://localhost:3002
```

## 对 1052-OS 的参考价值
- **多平台分发**：13平台支持可作为 1052-OS 社交自动上传的参考

## 适用场景
- 自媒体矩阵运营：多平台一键分发
