# 项目控制联盟

## 核心主题
面向工程建设领域项目控制（Project Controls）从业者的专业社区平台，覆盖 FIDIC/NEC/JCT 合同范本、EVM 赢得值管理、P6/Procore 软件应用，为工程数字化提供方法论支撑。

## 方法论/认知框架

**项目控制（Project Controls）六维体系**（从本文蒸馏，可复用）
| 维度 | 核心方法论 | 工具 |
|------|------------|------|
| 进度控制 | 关键路径法（CPM） | P6 / Microsoft Project |
| 费用控制 | ACE费用管理标准 | Excel / P6 |
| 工期索赔 | SCL协议（延误分析） | Primavera Risk Analysis |
| 合同管理 | FIDIC/NEC/JCT对比 | 合同范本库 |
| 交付管理 | AWP（先进工作包交付） | Procore |
| 风险管理 | 精益建造 + EVM | Primavera Risk |

**FIDIC vs NEC vs JCT 合同核心差异**
| 维度 | FIDIC | NEC | JCT |
|------|-------|-----|-----|
| 适用 | 国际工程 | 英国/英联邦 | 英国建筑 |
| 计价 | 单价合同为主 | 多种选择 | 总价合同为主 |
| 争议解决 | DAB（争议裁决委员会） | 分级解决 | 仲裁 |
| 变更 | 工程师裁定 | 项目经理裁定 | 建筑师裁定 |

**赢得值管理（EVM）三核心指标**
```
PV（Planned Value）计划值
EV（Earned Value）赢得值
AC（Actual Cost）实际成本

CPI = EV / AC  （成本绩效指数，<1 超支）
SPI = EV / PV  （进度绩效指数，<1 滞后）
```

## 操作流（FIDIC 工期索赔 SOP）

### 第一步：事件记录
发生延误事件当日 → 发出 Notice（NOD，Notice of Delay）

### 第二步：影响分析
用 P6 跑关键路径 → 计算延误天数 → 关联合同Clause

### 第三步：提交索赔
按 SCL 协议格式 → 提交 Detailed Claim Report

### 第四步：谈判/争议解决
DAB 裁决 → 不服 → 仲裁

## 金句
> "项目控制不是做表，是用数据说话——PV/EV/AC 三杆标尺，项目健康不健康一看便知。"

## 适用场景
- 国际工程项目：FIDIC 合同管理 + EVM 赢得值
- 国内大型工程：P6 进度计划 + 费用控制
- 工程法律顾问：工期索赔/争议解决
- 不适用：小型装修项目（方法论过重）
