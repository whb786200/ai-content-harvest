# 工程行业SKILLS入门指南蒸馏

## 核心主题
工程从业者如何用自然语言编写SKILL，把重复工作交给AI。"会用AI工具的人与会写SKILLS的人是完全两个层次——前者是乘客，后者是司机。"

## 方法论/认知框架

**SKILL定义**
> 把重复工作交给AI的"说明书"，训练专属于你的数字助手

**SKILL五大组成部分**
```
1. 触发条件（什么时候启动）
2. 输入数据（处理什么信息）
3. 处理步骤（按什么顺序做什么）
4. 输出结果（产出什么）
5. 异常处理（出错了怎么办）
```

**四步编写法**
```
Step 1: 选任务 → 每周≥2次、每次>30分钟、步骤固定
Step 2: 拆解为"输入-处理-输出"
Step 3: 自然语言描述（无需编程）
Step 4: 测试迭代固化
```

**SKILL价值公式**
```
SKILL价值 = 单次节省时间 × 执行次数
```
