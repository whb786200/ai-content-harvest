# 96个作品涨粉187.2万！卡通轻动漫制作

## 核心主题
治愈系卡通轻动漫 AI 视频爆款方法论：统一 IP 人设 + 治愈文案 + 豆包/即梦工具链，96个作品涨粉187.2万，对标账号「水豚噜噜」。

## 方法论/认知框架

**治愈系 AI 动漫爆款公式**（从本文蒸馏）
```
爆款 = 统一IP人设（水豚噜噜形象固定）
         + 治愈文案（温暖/萌系/正能量）
         + 人设-文案-画面高度契合
         + 日更/高频更新
```

**AI 卡通动漫四步法**
1. **IP定妆照**：结构化提示词锁定外貌/服装/装饰/表情（一次生成，后续复用）
2. **分镜脚本**：豆包+IP定妆照 → 10秒内治愈分镜
3. **动态画面**：Seedance2.0 + IP定妆照 + 脚本 → 视频片段
4. **剪辑输出**：剪映合成 + BGM

**IP 人设结构化提示词模板**
```
人物：[名字]，[年龄感]，[物种]
外貌：[发色][发型]，[眼睛颜色][眼型]
服装：[主色调]系，[风格]，[配饰]
表情：[常态表情]
场景：[典型场景]
画风：卡通轻动漫，治愈系，[色彩基调]
```

## 操作流

### 第一步：IP 定妆照（关键！）
用豆包生成结构化提示词，锁定 IP 外貌/服装/装饰/表情，生成定妆照（后续所有视频复用同一 IP）

### 第二步：AI 写分镜脚本
> 提示词："我是[IP名]，帮我写10秒治愈系动漫分镜脚本，包含场景/动作/对白，与我的IP人设高度契合"

### 第三步：Seedance2.0 生成动态画面
上传 IP 定妆照 + 分镜脚本 → 生成视频片段（保持角色一致性）

### 第四步：剪映合成
1. 导入所有视频片段
2. 添加治愈系 BGM
3. 添加字幕（治愈文案）
4. 导出：9:16竖屏
