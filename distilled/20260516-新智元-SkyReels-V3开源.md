## 操作流（本地部署 SkyReels-V3）

### 第一步：获取代码
```bash
git clone https://github.com/SkyworkAI/SkyReels-V3.git
cd SkyReels-V3
```

### 第二步：安装依赖
```bash
pip install -r requirements.txt
# 需要 PyTorch + CUDA 12.x，显存 ≥ 16GB
```

### 第三步：参考图转视频
```bash
python inference.py \
  --ref_images path/to/ref1.jpg,path/to/ref2.jpg \
  --prompt "人物转身，镜头缓慢推进" \
  --output output.mp4
```

### 第四步：视频延长（5s→30s）
```bash
python extend_video.py --input output.mp4 --target_duration 30
```

### 第五步：音频驱动数字人
```bash
python talking_head.py \
  --portrait path/to/portrait.jpg \
  --audio path/to/voice.wav \
  --output talking.mp4
```
