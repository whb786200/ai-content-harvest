# PromptHub — Prompt管理蒸馏

## 核心主题
PromptHub：解决多工具（Claude Code/Cursor/Codex/Windsurf/Gemini CLI）同时使用时代理/Skill分散难管理的问题。四层核心能力：Prompt管理/Skill管理/多平台分发/资产安全。

## 方法论

**核心认知**
> "Skill是独立于Prompt的资产类型——封装了指令、执行边界、配套资源的可复用能力包"

**四层核心能力**
| 层级 | 能力 |
|------|------|
| Prompt管理 | 分类存储、变量模板、版本回溯对比 |
| Skill管理 | 扫描本地Skill、预览结构、版本差异对比 |
| 多平台分发 | 一键安装到Claude Code/Cursor/Codex/Windsurf/Gemini CLI |
| 资产安全 | 本地优先 + WebDAV多设备同步 |

## 对1052-OS的参考价值
- **多平台分发**：1052-OS的skill管理可借鉴此思路
- **Skill是独立资产**：与1052-OS的SKILL.md体系理念一致
- **版本差异对比**：skill迭代时的diff能力很重要

## 适用场景
- 多AI工具用户：统一管理和分发Prompt/Skill
- 团队：共享Skill库和Prompt模板
- 个人：跨设备同步AI工作流配置

PromptHub是Prompt和Skill统一管理器（650+星）。解决多工具同时使用时代理/Skill分散问题。四层能力：Prompt管理（分类/变量模板/版本回溯）、Skill管理（扫描/预览/版本对比）、多平台分发（Claude Code/Cursor/Codex等一键安装）、资产安全（本地优先+WebDAV同步）。
