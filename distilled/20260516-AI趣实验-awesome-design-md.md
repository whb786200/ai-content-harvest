# awesome-design-md — 设计系统蒸馏

## 核心主题
awesome-design-md：55个顶级设计系统的DESIGN.md模板库（27.3K Stars），复制→粘贴→告诉AI"照这个样子做"，即可获得像素级完美UI。本质是"设计规范即提示词"。

## 方法论

**DESIGN.md 9个标准化部分**
```
1. 视觉主题与氛围
2. 色彩调色板（语义化命名）
3. 排版规则（字体层次）
4. 组件样式（按钮/卡片/表单）
5. 布局原则（间距/网格）
6. 深度与高度（阴影/层次）
7. 设计规范（最佳实践/禁忌）
8. 响应式行为（断点/适配）
9. AI提示指南（即用型提示词）
```

**使用流程（2步）**
1. 复制DESIGN.md到项目目录
2. 告诉AI："按照DESIGN.md规范，帮我做一个XX页面"
