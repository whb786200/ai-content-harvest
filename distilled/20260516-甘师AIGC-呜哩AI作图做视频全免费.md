## 操作流（wuli.art）

### 第一步：文生图
1. 访问 wuli.art
2. 输入中文 prompt（"古风水墨，汉服男子，中式养生"）
3. 选择比例（9:16 竖屏 / 16:9 横屏）
4. 生成 → 下载高清图

### 第二步：图生视频
1. 上传已生成图片
2. 输入动作描述（"人物缓慢转身，衣袖飘动"）
3. 选择时长（5秒）
4. 生成 → 下载视频

### 第三步（进阶）：批量生产
用同一套 prompt 生成多张图 → 批量转视频 → 剪映合成
