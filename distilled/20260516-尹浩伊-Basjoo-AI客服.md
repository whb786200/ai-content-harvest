# Basjoo AI客服系统蒸馏

## 核心主题
Basjoo：开源AI客服系统，一键部署脚本，技术栈 FastAPI + Next.js + Qdrant + Docker Compose，支持多语言自动识别回复、知识库管理、会话接管。

## 工具信息
| 属性 | 值 |
|------|-----|
| GitHub | github.com/haoyiyin/basjoo |
| 技术栈 | FastAPI + Next.js + Qdrant + Docker Compose |
| 部署 | 一条curl命令完成安装 |

## 核心功能矩阵
| 模块 | 能力 |
|------|------|
| **Agent配置** | 选模型、调参数、设人设，Playground测试 |
| **知识库** | 导入官网链接自动爬取、上传PDF/FAQ |
| **Q&A管理** | 手动/批量创建问答对，优先级最高 |
| **会话监控** | 实时查看、一键接管回复 |
| **Widget外观** | 颜色/位置/语言/自动弹出自定义 |
| **多语言** | 自动识别与回复（西班牙语/法语/阿拉伯语等） |

## 操作流

**部署命令（一行）**
```bash
curl -fsSL https://raw.githubusercontent.com/haoyiyin/basjoo/main/install-deploy.sh | sudo sh
```

## 适用场景
- 外贸独立站：多语言自动客服，24小时在线
- 跨境电商：降低客服人力成本
- 中小企业：零成本部署自有AI客服

## 文章摘要
Basjoo是开源AI客服系统，技术栈FastAPI+Next.js+Qdrant+Docker Compose。核心功能：24小时自动接待、多语言自动识别回复、引导客户留联系方式、对话记录管理与线索跟进。后台支持Agent配置/知识库/Q&A管理/会话监控/Widget自定义。一条curl命令即可完成部署。
