# Jellyfish（水母）— AI短剧工业化生产蒸馏

## 核心主题
Jellyfish：一站式AI竖屏短剧生产工具，3.3K+ GitHub星，Apache-2.0可商用。核心亮点是角色/场景一致性三重保障机制，六步工业化流水线从剧本到成片导出。

## 方法论/认知框架

**AI短剧一致性三重保障**（解决当前AI视频最大痛点）
```
1. 全局种子防漂移 → 整个项目统一随机种子，角色面貌始终一致
2. 风格强制继承 → 所有生成内容自动继承全局风格设定
3. 资产复用体系 → 角色/场景/道具/服装全生命周期管理
   └─ 双层库：项目级（本剧专用） + 全局级（跨剧复用）
```

**六步工业化流水线**
```
剧本输入 → 智能分镜 → 资产管理 → AI视频生成 → 后期剪辑 → 一键导出
```
