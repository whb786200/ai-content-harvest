# AI+中式养生短视频，3步0门槛上手

## 核心主题
中式养生赛道 + AI 工具链（豆包+即梦+剪映）0门槛制作爆款短视频：3条作品涨粉5万+，获赞33万+，工具仅需豆包+剪映。

## 方法论/认知框架

**AI 养生短视频三步法**（从本文蒸馏，可复用）
```
Step1: AI写文案（豆包）→ 中式养生技巧，50字/条，通俗不晦涩
Step2: AI生成画面（豆包+即梦）→ 古风水墨风，汉服儒雅男子
Step3: 剪映合成 → 10段×5秒 ≈ 50秒成片
```

**中式养生爆款内容公式**
```
爆款潜力 = 古风水墨视觉（差异化）
            + 中医常识（可信度）
            + 简单可操作（低认知负担）
            + 中老年受众（流量蓝海）
```

**AI 短视频变现四级阶梯**
| 阶段 | 方式 | 收益 |
|------|------|------|
| 0-1万粉 | 平台分成 | 低 |

## 操作流

### 第一步：AI 写文案（豆包）
复制指令发送给豆包：
> "帮我写10条适合中年人的中式养生小技巧，简单易操作，不涉及复杂工具，每条控制在50字以内，结合中医常识，语言通俗不晦涩"

### 第二步：AI 生成画面（豆包）
1. 让豆包生成画面描述词（古风水墨风，汉服儒雅男子，贴合养生技巧，每条80字左右）
2. 用豆包图片生成功能出图
3. 图片转视频：选择满意图片，填入养生动作描述，720P分辨率，5秒时长
4. AI 自动让画面动起来（热气飘动、手部轻微动作等）

### 第三步：剪映合成
1. 导入10个5秒视频到 timeline
2. 添加文本：每条养生技巧文案（如"睡前泡脚，助眠安神"）
3. 总时长：10×5秒 ≈ 50秒成品短视频
4. 导出：竖屏 9:16，1080P
