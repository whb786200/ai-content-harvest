# KB 2.0 — Karpathy知识库改造蒸馏

## 核心主题
白羊武士对Karpathy知识库方案（LLM as Compiler）进行五大改造：自动入库流水线+交叉链接+三层索引+Lint健康检查+多Agent协作规范，解决原版"垃圾进垃圾出/知识孤岛/无健康检查/无法协作"四大问题。

## 方法论/认知框架

**Karpathy原版四大问题**
1. 没有质量控制（垃圾进垃圾出）
2. 知识是孤岛（文档间无关联）
3. 没有健康检查
4. 多Agent无法协作

**五大改造**
| 改造 | 内容 |
|------|------|
| 自动入库流水线 | 抓取→结构化→质量打分→路由（≥18 keep，12-17 queue，<12 discard） |
| 交叉链接 | 入库后自动搜索已有笔记互链 |
| 三层索引 | index.md（目录）+ recent.md（最近10条）+ active.md（当前研究） |
| Lint健康检查 | 每周自动：矛盾/孤立/缺失/过时/反写/规则 六项检查 |
| 多Agent协作规范 | 读/Ingest/Crosslink/Lint可自主，删/归档/Writeback须问用户 |
