## 方法论框架

### 三层认知模型（认知科学→Agent映射）

| 记忆类型 | 定义 | Agent映射 | 核心特征 |
|---------|------|-----------|---------|
| 情景记忆 | 特定事件(何时何地) | 对话日志/工具轨迹 | 时序锚定 |
| 语义记忆 | 声明性事实/关系 | 用户画像/实体关系图 | 无时间性 |
| 程序记忆 | "如何做"的技能流程 | 工作流/工具使用习惯 | 行为指导 |

> 程序记忆工具化程度最低；Letta的sleeptime agent（对话间隙后台重写整合记忆块）最接近实用化。

### 混合向量-图谱存储（2026事实标准）

```
纯向量局限:
  ✗ 关系盲区（答不了"Alice与Bob关系"）
  ✗ 时序失忆
  ✗ 冲突无感

混合架构:
  向量库(语义相似/BM25/模糊) + 知识图谱(实体关系/时序标注/冲突检测)
  → 多信号检索融合
```

### 四大框架对比

| 框架 | Stars | 范式 | 领先维度 | 评测成绩 |
|------|-------|------|---------|---------|
| Mem0 | ~48K | 向量+实体链接 | 规模/易用性 | LoCoMo 92.5 |
| Zep/Graphiti | ~24K | 时序知识图谱 | 时序推理领先15分 | LongMemEval 63.8% vs Mem0 49.0% |
| Letta | ~21K | OS风格运行时 | 长时间运行Agent | LoCoMo文件系统模式 74.0% |
| Cognee | ~12K | ECL管道+类型化图谱 | 知识密集型 | - |

### Mem0 v3核心特性

- 三通道并行：Vector + BM25 + Entity Matching
- LoCoMo时间推理 +29.6，多跳 +23.1
- 四层作用域：User(跨会话永久) / Agent / Session / Organization
- 检索排名：用户 > 会话 > 原始历史
- 移除外部图存储改内置实体链接

### Letta分级存储架构

| 层级 | 定位 | 特征 |
|------|------|------|
| Core | RAM永驻 | 高速访问 |
| Archival | 向量存储 | 长期记忆 |
| Recall | SQL日志 | 事件追溯 |
| Filesystem | 文件系统 | LoCoMo 74.0% |

### 记忆过时检测四策略

| 策略 | 方法 |
|------|------|
| 时间衰减 | 基于时间权重衰减 |
| 显式过期 | 设置TTL过期时间 |
| 主动验证 | LLM定期一致性检查 |
| 用户反馈驱动 | 基于用户反馈更新 |

### 安全与隐私两大挑战

```
1. 记忆投毒:
   攻击: 构造交互让Agent记恶意信息
   防御: 输入验证/来源分级/记忆审计/沙箱隔离

2. GDPR被遗忘权:
   要求: 从向量/图谱/缓存/备份彻底清除
   难点: 图记忆与缓存层实现成本高
```

### 2026五大关键趋势

1. 混合存储默认化
2. 评测标准化（LoCoMo·LongMemEval·BEAM）
3. 记忆即上下文工程（Anthropic）
4. 声明式与自动提取融合（CLAUDE.md+管道）
5. 隐私优先（OpenMemory MCP本地优先）

> 未来18个月最值得关注：**程序记忆工具化**（学"怎么做"）+ **跨Agent记忆共享**

## 关键洞察

1. **混合向量-图谱存储是2026事实标准**：纯向量三大局限（关系盲区/时序失忆/冲突无感）已被业界共识，混合架构是多信号检索融合的基础
2. **程序记忆工具化程度最低但最有价值**：情景和语义记忆已有成熟方案，但"如何做"的技能流程记忆——未来18个月最值得关注
3. **Mem0 v3三通道并行(Vector+BM25+Entity Matching)是工程最优解**：LoCoMo 92.5+时间推理+29.6+多跳+23.1——综合最优
4. **Zep/Graphiti双时序标注不调LLM是低延迟关键**：LongMemEval 63.8% vs Mem0 49.0%——时序推理领先14.8pp
5. **Letta sleeptime agent最接近程序记忆实用化**：对话间隙后台重写整合记忆块——异步记忆整合是方向
6. **记忆投毒是Agent安全新战场**：构造交互让Agent记恶意信息——输入验证/来源分级/记忆审计/沙箱隔离四层防御
7. **GDPR被遗忘权在图记忆+缓存层成本高**：需从向量/图谱/缓存/备份彻底清除——隐私合规是工程挑战
