# Video2X：AI视频画质修复神器

## 核心主题
开源 AI 视频画质修复工具 Video2X：低分辨率/低帧率视频的 AI 放大修复 + 补帧优化，1.7万 Star，无需 Python 环境，开箱即用。

## 方法论/认知框架

**AI 视频修复算法选型矩阵**（从本文蒸馏）
| 内容类型 | 推荐算法 | 原理 | 效果 |
|----------|----------|------|------|
| 二次元/动漫 | Anime4K 或 Real-CUGAN | 线条锐利、色彩纯净 | 最佳 |
| 真人/录像 | Real-ESRGAN | 还原纹理细节 | 最佳 |
| 补帧需求 | RIFE 算法 | 15/24帧→60帧+ | 平滑流畅 |

**视频修复质量评判三要素**
1. **分辨率**：540P→1080P / 1080P→4K
2. **帧率**：24fps→60fps（RIFE 补帧）
3. **纹理还原**：Real-ESRGAN > 传统插值

## 操作流

### 第一步：下载安装
1. 访问 github.com/k4yt3x/video2x
2. 下载 Release 安装包（Windows）
3. 解压后双击 exe 启动（无需 Python 环境）

### 第二步：选择算法
- 二次元内容 → 选 Anime4K 或 Real-CUGAN
- 真人/录像 → 选 Real-ESRGAN
- 需要补帧 → 勾选 RIFE 算法

### 第三步：执行修复
1. 拖入低分辨率视频
2. 设置输出分辨率（如 1080P）
3. 点击开始 → 等待处理（需独立显卡）
4. 输出修复后视频

## 硬件要求
- 显卡：NVIDIA GTX600 系列及以上 / AMD 显卡（需支持 Vulkan）
- 集显/老旧笔记本：无法运行
- 显存：建议 ≥ 4GB
