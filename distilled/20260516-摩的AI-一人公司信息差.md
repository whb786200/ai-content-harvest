# 一人公司 — 信息差变现蒸馏

## 核心主题
一人公司核心公式：信息整合能力 + 个人品牌信任度。三层收益逻辑：搬运工（标品）→创作者（课程）→IP与系统（解决方案），月入5万的核心是从L1升级到L3。

## 方法论/认知框架

**三层收益逻辑**
```
L1 搬运工：整合信息卖标品（9.9-49.9元）
L2 创作者：加工解读卖课程（199-499元）
L3 IP与系统：方法论体系卖解决方案（999元+）
```

**启动四步**
1. 选赛道：信息分散+有付费意愿+自身不反感
2. MVP：最简陋可用产品，4.9-9.9元验证闭环
3. 高频输出：日更倒逼知识体系化
4. 非标溢价：叠加信任/效率/服务价值
