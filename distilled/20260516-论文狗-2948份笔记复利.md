# 2948份笔记复利之路蒸馏

## 核心主题
论文狗用Claude Code + graphify Skill，将2948份原始文件（代码/文档/PDF/图片）转化为结构化知识图谱，Token从428K降至6K（降低71.5倍），发现跨文档隐藏关联。

## 方法论/认知框架

**五阶段流水线（graphify）**
```
1. 检测 → 按扩展名分为代码/文档/PDF/图片
2. 提取 → 代码用tree-sitter AST，文档用Claude提取概念，
           PDF提取引用网络，图片用Claude Vision
3. 建图+聚类 → NetworkX构建图 + Leiden算法社区发现
4. 分析+报告 → 核心节点、意外关联、推荐问题
5. 导出 → 交互式HTML、Obsidian笔记库、JSON持久化
```

**关键数据**
- 2948份文件 → 8个概念页面 + 3个实体页面 + 19个资料摘要 + 1个查询归档
- Token消耗：428K → 6K（**降低71.5倍**）
- 81%关系为EXTRACTED（明确存在），19%为INFERRED（推理得到）
