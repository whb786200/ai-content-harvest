# Vidu Q2参考生Pro：万物可参考的视频生成

## 核心主题
Vidu Q2 参考生Pro 功能：通过参考素材（视频/图片）精准控制 AI 视频生成效果，支持特效复刻/表情复刻/材质替换/视频编辑，零门槛。

## 方法论/认知框架

**AI 视频参考控制三级精度**（从本文蒸馏）
| 精度级 | 参考类型 | 控制力度 | 适用场景 |
|--------|----------|----------|----------|
| L1 风格参考 | 1张参考图 | 低（仅风格） | 风格迁移 |
| L2 动作参考 | 参考视频 | 中（动作+ timing） | 舞蹈/运动复刻 |
| L3 多模态参考 | 2视频+4图 | 高（全要素控制） | 商业广告/IP内容 |

**参考生 Pro 五类核心能力**
1. **特效复刻**：上传参考视频+目标素材 → 3秒解析并复刻特效
2. **表情复刻**：角色图+参考视频 → 精准模仿表情
3. **材质替换**：更换物体颜色/质感（塑料杯→青花瓷）
4. **视频编辑**：加元素/删物体/换背景/替换主体
5. **多模态输入**：2个参考视频+4张参考图同时输入

## 操作流

### 第一步：特效复刻
1. 准备参考视频（含目标特效）
2. 准备目标素材（要添加特效的物体/人物）
3. 上传至 Vidu Q2 参考生Pro
4. 等待3秒解析 → 生成复刻视频

### 第二步：表情复刻
1. 准备角色图（静态）
2. 准备参考视频（含目标表情）
3. 上传 → 生成表情精准模仿视频

### 第三步：材质替换
1. 上传原物体图片
2. 输入目标材质描述（"青花瓷材质，釉面光泽"）
3. 生成材质替换视频
