# 8条作品涨粉18万！AI古诗动画全流程

## 核心主题
AI 古诗动画爆款方法论：用 DeepSeek/豆包生成分镜脚本 → 即梦 AI 生成配图/视频 → 剪映合成，78条作品涨粉31.7万。

## 方法论/认知框架

**AI 短视频爆款公式**（从本文蒸馏，可复用）
```
爆款 = 情感共鸣（古文回忆杀）
         + 低门槛工具链（豆包+即梦+剪映）
         + 固定开头模板（"曾经死记硬背的古文，用AI重新演绎"）
         + 高频更新（日更/隔日更）
```

**AI 视频内容产品化三步法**
1. **选题定位**：选有情感共鸣的垂类（古诗/养生/历史）
2. **工具链固化**：选定工具组合，每次复用（豆包→即梦→剪映）
3. **模板化生产**：固定开头/结构/时长，批量化

**分镜脚本标准化格式**（40-50个分镜）
| 字段 | 说明 |
|------|------|
| 镜号 | 序号 |
| 画面 | 场景描述 |
| 景别 | 远/全/中/近/特 |
| 视角 | 平/仰/俯 |
| 对白 | 古诗原文/配音文字 |
| 提示词 | 即梦生图 prompt |

## 工具链
| 工具 | 用途 | 费用 |
|------|------|------|
| DeepSeek/Kimi/豆包 | 生成分镜头脚本 | 免费/付费 |
| 即梦 AI（图片3.0） | 分镜配图，1K画质，9:16 | 付费 |
| 即梦 AI（视频3.0） | 图片转视频片段，5秒/段 | 付费 |
| 剪映 | 合成成片+配音+字幕+BGM | 免费/付费 |

## 操作流

### 第一步：AI 写分镜脚本
提示词发给豆包/Kimi：
> "帮我写古诗《XXX》的40-50个分镜脚本，包含镜号/画面/景别/视角/对白/提示词，适合古风动画视频"

### 第二步：即梦 AI 生成分镜图片
- 模型：图片 3.0
- 画质：1K
- 比例：9:16（竖屏）
- 每个分镜对应1张图

### 第三步：即梦 AI 图生视频
- 模型：视频 3.0
- 时长：5秒/段
- 共 40-50 段视频片段

### 第四步：剪映合成成片
1. 导入所有 5秒视频片段到 timeline
2. 添加配音（古风男声/女声 AI 配音）
3. 添加字幕（古诗原文）
4. 添加古风 BGM
5. 总时长：40镜 × 5秒 ≈ 3-4分钟

## 适用场景
- 教育类自媒体：古诗/历史/成语故事动画化
