# 公众号发布Skill蒸馏

## 核心主题
MCP方案连接微信公众号有致命缺陷（进程崩溃/tool not found/多账号需开多个进程）。Skill+curl直接调用微信官方REST API是更可靠的方案，Token两小时过期每次现取，无状态调用最稳定。

## 方法论/认知框架

**MCP方案三大致命问题**
```
1. MCP进程经常崩溃 → "tool not found"错误
2. 多账号需开多个进程存密钥 → 资源浪费
3. 有状态连接不稳定 → 微信API本身是无状态的
```

**Skill+REST方案优势**
| 维度 | MCP方案 | Skill+curl方案 |
|------|---------|----------------|
| 稳定性 | 进程常崩溃 | 每次独立调用 |
| 多账号 | 需多进程 | 单脚本切换 |
| Token管理 | 需持久化 | 每次现取 |
| 调试 | 黑盒 | curl可直接测试 |

## 微信公众号HTML踩坑指南

| 坑点 | 说明 | 解决方案 |
|------|------|----------|
| `<strong>`不能加style | 微信渲染成块级元素 | 用`<span style="font-weight:bold">` |
| 列表标签间不能有空白 | 否则出现额外空白项 | 压缩HTML，删除标签间空白 |
| 外部图片全被屏蔽 | 必须上传到微信CDN | 先用微信API上传图片拿media_id |
| class/id全被剥离 | 所有样式必须inline | 用inline-style，不能用CSS类 |
| 表格深色背景 | 白色文字可能变透明 | 明确指定文字颜色 |

## 操作流

**微信API调用流程**
```bash
# 1. 获取access_token（2小时有效）
curl "https://api.weixin.qq.com/cgi-bin/token?grant_type=client_credential&appid=APPID&secret=APPSECRET"

# 2. 上传图片拿media_id
curl -F "media=@/path/to/image.jpg" "https://api.weixin.qq.com/cgi-bin/material/add_material?access_token=TOKEN&type=image"

# 3. 发布草稿
curl -X POST -H "Content-Type: application/json" \
  -d '{"articles":[...]}' \
  "https://api.weixin.qq.com/cgi-bin/draft/add?access_token=TOKEN"
```

## 对1052-OS的参考价值
- **Skill+curl方案**：1052-OS的wechat-publish Skill应参考此方案（不用MCP，用REST）
- **HTML踩坑指南**：1052-OS公众号发文必须遵循这些规则
- **无状态调用**：每次现取Token，避免持久化带来的过期问题

## 金句
> "微信公众号API只有5个端点，全是无状态REST调用。Skill+curl，比MCP稳定10倍"

- 多账号管理：一个Skill脚本切换多个公众号
- 内容创作者：绕过MCP坑，稳定发布
