# llm-wiki-skill — Karpathy知识库蒸馏

## 核心主题
llm-wiki-skill：将Andrej Karpathy的知识管理方法封装为Claude Code Skill，一键安装后AI自动将raw/素材编译为结构化Wiki，知识一次编译、持续维护、不断复利。

## 方法论

**Karpathy知识管理核心**
> "将LLM作为知识增量编译器（非搜索引擎），知识一次编译、持续维护、不断复利"

**使用流程**
1. 无需分类，素材直接丢入raw/
2. AI自动生成结构化Wiki
3. 自然语言查询，答案可自动存回Wiki
4. 定期健康检查（矛盾/孤立/过时）
