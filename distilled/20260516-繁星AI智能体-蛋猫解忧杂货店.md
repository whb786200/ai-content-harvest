# 蛋猫解忧杂货店：31条涨粉631.6万

## 核心主题
治愈系 IP 化 AI 视频爆款方法论：拟人化卡通角色 × 沉浸式治愈场景 × 戳心情绪文案，31条作品涨粉631.6万，单品破百万赞。

## 方法论/认知框架

**治愈系 IP 爆款公式**（从本文蒸馏，可复用）
```
爆款 = 拟人化卡通角色（蛋猫）
         × 沉浸式治愈场景（解忧杂货店）
         × 戳心情绪文案（低焦虑/高共情）
         + IP 固定形象（角色一致性）
         + 稳定日更
```

**AI 治愈系视频四步法**
1. **AI 生成分镜脚本**（豆包 AI + 预设提示词，固定 IP 人设）
2. **生成角色固定形象**（上传对标角色 → 替换主体生成专属 IP）
3. **视频生成**（即梦 Seedance 2.0，16:9，15秒/段，以首段为参考补充）
4. **剪映二次创作**（音频提取+换 BGM+转场+水印+固定开场结尾）

**IP 运营三级变现阶梯**
| 阶段 | 方式 | 收益 |
|------|------|------|
| 初期（0-10万粉） | 平台分成 | 低 |
| 中期（10-100万粉） | 私域付费课程 | 中高 |
| 长期（100万+粉） | IP 多元化变现（周边/联名） | 高 |

## 操作流

### 第一步：AI 生成分镜脚本（豆包 AI）
提示词模板：
> "你是[IP名]，帮我写10个治愈系分镜脚本，每个15秒以内，风格：[治愈/戳心/低焦虑]，包含：镜号/画面描述/对白/情绪节点"

### 第二步：生成角色固定形象
1. 上传对标角色图片（如蛋猫）
2. 使用"替换主体"功能 → 生成专属 IP 形象
3. 固定形象用于所有后续视频（保持一致性）

### 第三步：即梦生成视频
1. 模型：Seedance 2.0
2. 画幅：16:9
3. 时长：15秒/段
4. 以首个15秒为参考 → 继续补充生成后续片段
5. 下载所有视频片段

### 第四步：剪映二次创作
1. 导入视频片段
2. 音频提取（保留原声/或换 AI 配音）
3. 换 BGM（治愈系：轻音乐/自然音）
4. 添加转场（柔和过渡）
5. 添加固定开场（如"欢迎来到蛋猫解忧杂货店"）
6. 添加固定结尾（引导关注）
7. 去水印+加个人水印
