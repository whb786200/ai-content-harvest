# OiiOii+Seedance 2.0 — AI短剧蒸馏

## 核心主题
OiiOii（149种风格动画生成）+ Seedance 2.0（四模态输入/口型同步/2K）组成AI短剧封神搭档。虚拟制作团队五角色分工（艺术总监/编剧/角色设计师/场景设计师/分镜师），配合万能Prompt模板保障角色一致性。

## 方法论/认知框架

**虚拟制作团队五角色**
```
1. 艺术总监 → 确认影片长度/画面比例
2. 编剧 → 核对脚本
3. 角色设计师 → 生成主角主图（OiiOii）
4. 场景设计师 → 生成场景主图（OiiOii）
5. 分镜师 → Seedance 2.0满血版生成分镜
```

**角色一致性万能Prompt模板**
```
请生成一条适合持续连载的IP角色动画短片。
主角是【角色外形】、穿着【固定服装】、气质【角色气质】，
角色外观、服装、脸部特征、配色在所有镜头中必须保持一致。
故事发生在【核心场景】，角色要完成【动作主线】。
整体风格为【风格】，情绪为【情绪】，
要求镜头有起承转合，动作流畅，场景连续，光影统一。
```
