# AIHOT热点监控系统蒸馏（公众号版）

## 核心主题
卡兹克封装3年自媒体经验打造的AI热点监控系统：168信源→预筛→评分→权重→聚类→日报，核心理念"能用代码处理的就不用模型"。

## 方法论/认知框架

**六层处理架构**
```
采集层 → 168个精选信源（T1官方 > T1.5官推 > T2个人/KOL）
预处理层 → DeepSeek V3.2预筛，判断AI相关性
评分层 → DeepSeek V4 Pro五维独立评分
权重层 → 代码接管信源权重/类型权重/公司权重计算
聚类层 → Embedding语义聚类，同一事件展示最权威一条
日报层 → 每天8:00自动生成（模型发布/产品/行业/论文/技巧五大版块）
```

**评分迭代的经验教训**
| 版本 | 做法 | 结果 |
|------|------|------|
| V1-V6 | 模型直接打分 | 硬核论文90分，鸡汤87分，不可靠 |
| V7 | 人类反馈+规则迭代 | 规则越多泛化越差 |
| 最终版 | 模型基础评分+代码权重计算 | 成功 |

## 关键方法论

> "能用代码处理的就不用模型"

> "能用脚本就别用Agent"

## 数据规模
- 168 信源 / 563 条/天 / 预筛后精选几十条
- 日报生成仅需 1 秒（分类翻译在入库时完成）

## 适用场景
- 自媒体运营：热点信号监控
- 知识管理：信源分级与信息筛选方法论
- AI架构："模型+代码"混合架构的实践参考
